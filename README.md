**KPIs:** % entregas a tiempo (>95%), costo combustible/km, llamadas/día (-80%), tiempo planificación (1h → 1min)

**Cronograma:** Sprint 1 (sem 1-2) → Sprint 2 (sem 3-4) → Sprint 3 (sem 5-6)

## Objetivo SMART

Desarrollar un sistema DSS para FlashLogistics que reduzca el tiempo de planificación de rutas de 1 hora a 1 minuto (98% de reducción) y disminuya las entregas tardías del 30% al 5% mediante un algoritmo de optimización y trazabilidad GPS, en un plazo de 6 semanas.
